Mobile G-Code Editing

M.A.B. S1 — Mobile G‑Code Editing for CNC Operators

Inspect, preview, and update machine code anywhere in the shop — right from your phone or tablet.

The Problem

CNC work still depends on desktop editors, printed code, and bouncing between machines and screens. That slows down reviews, makes quick fixes harder, and increases the chance of mistakes when you need to inspect or adjust code quickly.

The Solution

M.A.B. S1 brings G‑code review and editing into a mobile workflow built for real CNC work. Import CNC files, inspect lines of code, preview tool movement, zoom in on the path, and make updates directly from your phone or tablet.

What M.A.B. S1 Does

  • Import CNC files quickly
  • Inspect G‑code line by line
  • Preview toolpath movement visually
  • Zoom in and out for closer review
  • Apply edits and export updated code
  • Keep the editing process simple enough for shop‑floor use

Why It Matters

When code is easier to access and review, operators can catch issues sooner and make small corrections without waiting for a desktop setup. That saves time, improves flexibility, and makes the CNC workflow more portable.

Built For

CNC operators, machinists, CNC programmers, shop supervisors, technical schools and training programs, and small manufacturing teams that need quick code access.

Current Stage

M.A.B. S1 is currently in closed testing and being refined for real‑world CNC use. The core experience is already working: file import, preview, scroll‑free inspection, and editing controls built for the shop floor.
